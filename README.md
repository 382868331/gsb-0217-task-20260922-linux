# antimeridian — 球面环线的日期变更线展开

在单位球面上，对一条由**唯一较短大圆弧**（short great-circle arc）连接的
闭环，计算其有向面积，并沿经度 180° 半子午线（国际日期变更线）把环分裂成
各自经度连续的渲染片段；穿过极点的交点单独标记为 `ambiguous`，整段贴着切缝
的边标记为 `coincident` 并原样保留。全部几何在三维单位向量上完成，**不对
经纬度做平面插值**，因此不会产生平面投影假交点。

本次增量：对同一简单有向大圆环所围区域，新增**三维面积一阶矩向量**
`M = ∫ x dA`、**二阶矩对称矩阵** `S = ∫ x xᵀ dA`，以及 `M ≠ 0` 时的
**归一方向重心** `M/|M|`（入口 `region_moments`，见下文「面积矩接口」）。
面积沿用既有 Gauss–Bonnet 计算；矩全部在三维单位向量上以球面散度定理
闭式边界积分求得，不使用经度展开，也不平均顶点冒充面积重心。

仅使用 Python 标准库。

## 接口

唯一核心入口（纯函数、无状态）：

```python
from antimeridian import unfold_loop

result = unfold_loop(points)                 # 经纬度均为弧度
result = unfold_loop(points, units="deg")    # 或角度
# 等价便捷封装： unfold_loop_degrees(points)
```

- `points`：3–100 个 `(lon, lat)` 二元组（也接受 `GeoPoint`）。环隐式闭合：
  自动补一条“最后一个顶点 → 第一个顶点”的边，**不要**重复传入首顶点。
- 角度约定：经度 `lon ∈ [-π, π]`（`+π` 与 `-π` 是同一条切缝），
  纬度 `lat ∈ [-π/2, π/2]`，单位弧度。
- 返回不可变的 `UnfoldedLoop`：

| 字段 | 含义 |
|---|---|
| `arcs` | 每条**原弧**参数 `ArcParam`：端点、圆心角 `central_angle ∈ (0,π)`、`pole_coincident`、`contains_pole` |
| `fragments` | 经度连续的渲染片段 `Fragment`（含边号、顺序、展开后的起止经度、起止纬度、`kind`、`pole`） |
| `seam_crossings` | 边与 180° 半子午线的**真实**交点 `SeamCrossing`（边号、弧参数 `t`、纬度、规范经度 `±π`） |
| `ambiguous_markers` | 极点事件 `AmbiguousMarker`（边号、`north/south`、弧参数 `t`、纬度），不自动连线 |
| `signed_area` | 有向面积，区间 `(-2π, 2π]` |
| `area_winding` | `"ccw"`（正）/ `"cw"`（负）/ `"zero"` |

片段 `kind`：

- `normal`：普通片段，内部不跨缝；
- `coincident`：整条原弧都在 180° 半子午线上，保持为一段、保留原弧，
  **不**生成跨缝的虚假连接；
- `ambiguous`：触及极点（内部穿极或极点为顶点）。极点的经度无定义，
  渲染器须自行决定如何连接，库不擅自拉直线。

展开后经度可以超出 `[-π, π]`（如 `170° → 190°` 表示东向跨过切缝），
从而保证同一物理顶点在相邻片段中经度一致；只有普通（非极点）连接连续，
极点连接被 `ambiguous` 断开。

## 面积矩接口（本次增量）

```python
from antimeridian import region_moments

m = region_moments(points)                 # 弧度
m = region_moments(points, units="deg")    # 角度；封装 region_moments_degrees
```

输入契约、校验与错误语义与 `unfold_loop` **完全相同**（同一 `_validate_loop`，
NaN/Inf/bool/对跖/自交/共大圆退化全部同样拒绝）。返回不可变的 `RegionMoments`：

| 字段 | 含义 |
|---|---|
| `signed_area` | 有向面积 `(-2π, 2π]`（与 `unfold_loop` 一致，左侧为正） |
| `area_winding` | `"ccw"` / `"cw"` / `"zero"` |
| `first_moment` | 有向一阶矩向量 `M = ∫ x dA`（三维 `(x,y,z)` 元组） |
| `second_moment` | 有向二阶矩对称矩阵 `S = ∫ x xᵀ dA`（3×3，按行元组） |
| `direction_centroid` | `M/|M|` 归一方向重心；`|M| ≤ 1e-12` 时为 `None` |

性质（均有测试锁定）：

- **有向性**：反转轮廓，`signed_area`、`M`、`S` 同时反号，方向重心反向，
  几何区域大小不变。
- **迹恒等**：`trace(S) = signed_area`（因 `|x| = 1`）。
- **旋转协变**：刚体旋转 `R` 后 `M → R M`，`S → R S Rᵀ`，方向重心随转。
- **可加性**：区域并（共同边抵消）的矩等于分块矩之和。
- **跨日期线透明**：全部在三维方向向量上积分，跨缝环无需任何特判；
  经度展开结果不用于面积或矩公式。
- 方向重心是**面积加权积分**的方向，不是顶点位置的平均（有专门测试
  防止退化为顶点平均）。
- 开半球内的区域必有 `M ≠ 0`；`M = 0`（方向重心为 `None`）只可能出现在
  跨半球均衡的区域（测试用精确调参的哑铃形区域覆盖此分支）。

矩的数学定义是"环左侧区域"的有向积分。左侧区域面积按 4π 取模表示在
`(-2π, 2π]`；当左侧为较大区域（面积 > 2π）时，利用全球面矩
`∫ x dA = 0`、`∫ x xᵀ dA = (4π/3) I` 修正为所围较小区域的有向矩，
从而 `trace(S) = signed_area` 恒成立。

## 错误语义

所有错误继承 `GeometryError`（也是 `ValueError`），并带可定位的
`location` 字符串（如 `"vertex 1.lat"`、`"edge 3"`、`"edges 1,3"`）：

- `InvalidInputError`：顶点数不在 `[3,100]`；`lon/lat` 越界；
  **NaN / ±Infinity**；**布尔值**当作数字（`deg` 模式同样拒绝）；
  顶点不是二元组；`units` 非法；相邻顶点重合（零长边）。
- `AntipodalAdjacentError`：相邻顶点（在 1e-12 守卫带内）对跖——短弧不唯一。
- `SelfIntersectionError`：两条**非相邻**边横截相交或重合（`edge_indices`
  给出边对）。相邻边共享顶点不算自交。
- `DegenerateLoopError`：所有顶点共面于同一大圆，两侧各包一个半球，
  有向面积无法唯一定义，直接报错而不是任意给符号。

非法输入一律抛错、**不静默纠正或夹紧**（仅对舍入进入 `±π/2`、`±π` 的
浮点做同值规范化）。API 为单个纯函数，校验全部通过后才构造结果，
因此失败不会留下任何部分状态。算法全部为闭式计算，没有迭代搜索，
故不存在“搜索预算耗尽”这一结果类别；任何拒绝都是确定可证的输入/几何违例。

## 算法与设计取舍

1. **三维大圆弧，而非平面经纬插值。** 经纬度先转单位向量。弧上点用
   SLERP 精确给出：
   `X(t) = sin((1-t)α)/sin α · P + sin(tα)/sin α · Q`，
   其中 `α = acos(P·Q) ∈ (0,π)` 为唯一短弧圆心角。
2. **切缝交点用平面相交闭式求解。** 180° 经线所在大圆是平面 `y = 0`
   （穿过 `(-1,0,0)` 与两极）。将它与弧所在大圆平面
   （法向 `P × Q`）求交，得到两个对跖候选点，再判定是否落在物理的
   **半**子午线（`x ≤ 0`，排除对面 0° 经线）且位于短弧内部。
   这保证交点是真实弧/缝交点。平面直连会算错：例如边
   `(170°,0)→(-170°,60°)`，平面插值在 `t=0.5`、纬度 30° 处过缝，而真实
   大圆弧在 `t≈0.6827`、纬度 **41.33°** 处过缝（相差逾 11°）。
3. **短弧至多一次穿缝。** 两个大圆至多交于一对对跖点，而长度小于 π 的
   短弧内部不可能同时经过一对对跖点，故每条边最多一个内部切缝交点。
4. **连续经度展开。** 交点位置由闭式几何精确定位；沿弧的**整数** `±2π`
   展开偏移由对精确 SLERP 点的经度卷绕表决定（仅用于整数选支，不用于
   定位交点，也不产生交点）。这正确处理了“端点规范经度分居切缝两侧、
   但短弧实际绕道 0° 经线”的情形。切缝点经度恒为精确的 `±π`，
   只从卷绕表读取其所在整数帧（避免近极点经度插值误差）。
5. **极点。** 内部穿极用“极点在弧所在大圆上且在短弧内部”判定（加弧长/
   SLERP 基函数两种独立判据在测试中互校）；穿极边分裂为两条定经线
   `ambiguous` 半段。极点为顶点时，在到达边上以 `t=1.0` 标记一次。
   近极（但非极）穿越用水平半径（线性量）判极，避免用二次量 `1-|z|`
   把近极点误判为极点。
6. **有向面积（左侧为正）。** 用 Gauss–Bonnet 逐顶点外角和：
   `A = 2π − Σ 转角`，切向量在顶点切平面内由精确大圆弧方向取得，
   `atan2` 给出带符号转角（左转/左侧为正），结果规范化进 `(-2π,2π]`。
   这是按 4π 取模的有向面积；对无自交简单环，其绝对值即所围较小区域面积。
7. **面积矩（球面散度定理闭式边界积分）。** 对切向投影场
   `P c = c − (c·x)x` 有 `div_S(P c) = −2(c·x)`，大圆弧的外余法向为常向量
   `−m`（`m = (P×Q)/|P×Q|`），故 `M = ½ Σ α_e m_e`。又
   `div_S((c·x) P d) = (c·d) − 3(c·x)(d·x)`，对 `(c,d)` 对称化并沿弧
   `x(s)=cos s·P + sin s·W`（`W=(Q−cosα P)/sinα`）积出
   `S[c,d] = (c·d)A/3 + (1/6) Σ_e [(d·m) I_c + (c·m) I_d]`，
   `I_c = (c·P) sinα + (c·W)(1−cosα)`。全部闭式，无数值积分、
   无经纬展开。左侧区域面积 `> 2π` 时用全球面矩修正（见上节）。

## 误差口径

双精度（IEEE-754 binary64）。

- **面积**：解析八分之一球三角形（面积 `π/2`）精确到机器精度
  （典型误差 0–9e-16）。核心（Gauss–Bonnet）与独立参考（Van Oosterom
  立体角公式）在 800+ 随机简单环上互校，观测最大绝对差约 `6e-15`，
  随机回归判定门限取宽松的 `delta=1e-9`；刚体三维旋转面积不变，
  测试容差 1e-11。解析精度是双精度舍入量级，而 1e-9 仅为防环境抖动的
  **判定门限**，不是用宽容差掩盖边界错误——自交/对跖/退化等边界均独立判定。
- **切缝交点参数 `t`、纬度**：闭式三维构造，双精度舍入（约 1e-12 弧度）。
  回归用例对 `t` 用 `delta=1e-8`、对纬度用 `1e-7` 弧度（约 0.02″）断言，
  并显式断言不等于平面插值结果。
- **角度守卫带**：对跖 `|P·Q+1| < 1e-12` 拒绝；重合顶点 `P·Q > 1-1e-12`
  拒绝；经线/极点判定阈值 1e-9（弧度）。这些是输入安全边界，不用于放宽
  面积断言。
- **面积矩**：闭式边界积分，双精度舍入量级。八分球三角形解析值
  （`M=(π/4)(1,1,1)`、`S` 对角 `π/6` 非对角 `1/3`）精确到机器精度；
  与独立高精度细分积分参考（`tests/moment_reference.py`，不导入被测核心）
  在凸/凹/跨日期线多边形上互校，核心闭式值与参考之差即参考自身的
  数值积分误差（观测 `≤ 4e-6`，判定门限 `1e-5`，远小于参考网格误差
  本身）；旋转协变 `R M`、`R S Rᵀ` 与迹恒等 `trace(S)=signed_area`
  的测试容差为 1e-12 量级。

## 已知限制 / 实现子集

- 只实现本题契约的数学子集：单位球、每边为**较短**大圆弧（圆心角 `< π`）、
  顶点 `≤ 100`、简单（非相邻边不自交）环。**不**宣称兼容 GeoJSON、S2、
  OGC 等任何行业标准，也不实现多多边形、孔洞、缓冲或投影转换。
- 不支持含对跖相邻点（短弧不唯一，按契约拒绝）、自交环、全共大圆退化环。
- 面积按 4π 取模表示在 `(-2π,2π]`；不区分“几何上覆盖多遍”的环
  （此类输入通常自交，已被拒绝）。
- 切缝整段重合（`coincident`）只覆盖“整条短弧位于 180° 半子午线”的情形；
  端点在切缝上、但短弧从另一侧绕回的几何上不可能（两点同半子午线，
  短弧即沿该子午线）。
- 近极但非极（角距离小于 1e-9 弧度 ≈ 0.00000006°）的穿越按普通切缝穿越
  处理；真正精确过极的弧才标 `ambiguous`。
- 未做多边形布尔运算或覆盖修正（overpass/fix）；本库只做单环展开。
- 面积矩按"环左侧区域"的有向积分定义（开半球输入时即所围区域本身）；
  `M = 0` 时方向重心无定义，输出 `None`（开半球内区域不会发生）。
  输入上限与展开接口相同（顶点 ≤ 100、短弧、简单环）。

## 关于独立参考

`tests/reference.py` **不导入** `antimeridian`：面积用 Van Oosterom
立体角扇形和（核心用 Gauss–Bonnet 转角和），切缝事件用对精确 SLERP 的
独立密采样（核心用平面闭式相交），穿极用加弧长判据（核心用 SLERP 基
反演）。两套独立推导一致才作为正确性依据；往返一致仅作补充，不作预言机。

`tests/moment_reference.py` 同样**不导入** `antimeridian`：从任意顶点扇形
三角剖分（有向三角形，凹环自动抵消），把每个球面三角形细分成
160×160 测地网格后数值累加 `x dA` 与 `x xᵀ dA`（微三角形有向面积用
Van Oosterom 公式、被积函数取微三角形质心）。核心则是散度定理闭式边界
积分——两条独立推导路径一致才作为正确性依据；该参考只作数值参照，
并用于核对矩的可加性，旧经度展开结果不作为面积/矩公式。
